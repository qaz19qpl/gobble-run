Gobble Run — a turkey's Thanksgiving escape. A side-scrolling chase game: outrun the farmer through the farmyard, the barn and the kitchen, jump fences and hay bales, duck under hanging pots, time the swinging carving knife, dodge the hot oven, grab corn and pumpkin pie, and reach the woods before the farmer grabs you. Title screen, live HUD (score, distance, lives, farmer gap), caught and escaped end screens with restart, and synthesized WebAudio sound — all static files, zero network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — Space / ↑ to jump, ↓ to duck, Shift to gobble-dash, P to pause, M to mute, R to restart.
